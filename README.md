A single-line office joke, written by a small deterministic Node program (stdlib only) to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. The joke: an employee asks HR for a raise and is handed a meditation app instead — so now they can calmly afford nothing. A fresh take on wellness perks standing in for pay, with the punchline landing where the reader doesn't expect it.
